# Optional agent notes

Role notes may live in `<agent-name>/MEMORY.md`. Create them only for useful,
verified Schisaciaccole facts, with dates and source paths; never store secrets.
The orchestrator integrates proposed notes to avoid concurrent writes.
The security reviewer only proposes notes and remains read-only.

This is a local file convention, not an automatic memory store. General project
notes use `../memory/MEMORY.md`. No notes from another project are retained.

# Shared project rules

Follow the root runtime instructions (`AGENTS.md` for Codex, `CLAUDE.md` for Claude), then the relevant domain rules. Implement the delegated brief and report files changed, checks run and any limitations. Do not commit unless the orchestrator assigns it; push only on explicit developer request.

Use current `README.org`, manifests and source as evidence. Do not invent credentials, URLs, versions or environment requirements. Keep `.env`, OAuth tokens, keychain contents and signing keys out of output and persistent notes.

When available, use graphify to locate relevant source areas, then verify against live files. Preserve unrelated working-tree changes and generated artifacts. Domain agents inherit session permissions; behavioral instructions do not create a separate sandbox.
